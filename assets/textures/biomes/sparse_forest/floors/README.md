# Sparse Forest — Floor Textures

Floor PNGs for the SparseForest biome. For the v1 prototype, the
SparseForest biome reuses the existing forest floor texture
(`assets/textures/biomes/forest/floors/forest floor_01.png`) so this
folder is intentionally empty. Drop sparse-forest-specific floor
variants (grass paths, dirt trails, leaf litter) here when you want to
diverge from the forest look.

Import settings: **Filter = Nearest** (same as the other biome
textures).
